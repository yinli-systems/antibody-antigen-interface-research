# Commit sequence policy

This repository was assembled from authenticated research artifacts after the
experiments had already been performed. Its Git history is a curated publication
history, not the original development history.

The 100 commits are ordered by the logical dependency chain of the work:

1. repository and evidence-handling policy;
2. core interaction and metric implementations;
3. data preparation and model adapters;
4. cluster execution templates;
5. automated verification;
6. split, homology, and leakage protocols;
7. SPPIDER-seq evidence;
8. partner-retrieval evidence;
9. MIPE diagnostics;
10. final figures and reports.

All commits use their real publication time. No author or committer date was
backdated to simulate a historical development timeline.
