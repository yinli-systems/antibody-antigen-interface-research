# Prospective temporal double-cold v2: sealed execution

This document specifies the independent-steward option for the one permitted
label opening. It does not authorize an opening by itself.

## What the model team supplies

- the frozen protocol and receipt;
- the frozen six-checkpoint binding and immutable model container;
- the accumulated candidate metadata and sequence-only qualification audit;
- sequence-predicted, per-chain geometry or the frozen deterministic predictor;
- a one-shot evaluator that emits aggregate results and an audit receipt.

The model team does not supply a candidate-removal interface, calibration
parameters learned from the cohort, or alternative checkpoints.

## What the steward keeps sealed

- experimental bound-complex coordinate files;
- residue-pair contact labels and their paratope/epitope marginals;
- per-instance predictions joined to labels;
- all interim or per-seed performance output.

The steward first verifies release dates, metadata suitability, CDR
completeness, sequence double-cold filters, both minimum sample-size gates, and
all supplied hashes. If any check fails, the steward returns only a signed
fail-closed receipt and does not compute task labels.

## The single opening

After the gate passes, the steward computes 4.5 Angstrom non-hydrogen atom
contact labels exactly once and runs the frozen evaluator. The returned package
contains aggregate metrics, eligible denominators, PDB-block bootstrap outputs,
software/container hashes, checkpoint hashes, and a signed audit receipt. It
does not expose per-instance labels before manuscript lock.

All outcomes must be reported. The result cannot be used for model selection,
calibration, threshold fitting, protocol changes, or a second opening.
