# Present every result in three layers

[Atlas](README.md) · [Cohorts](COHORTS.md) · [Findings](REVIEW_FINDINGS.md)

## Layer 1: landing page

Lead with bounded questions and a few protocol-scoped results, not a cross-cohort leaderboard. Final decisions such as 36/36 complete with no promotion are more informative than training counts. Newer manuscript claims need their own labelled evidence-pending section.

## Layer 2: uniform result cards

Each card includes answer, evidence level, cohort, model/input access, seeds, estimator/uncertainty, limitations and exact source links. Put controls and negative endpoints beside gains. Separate interface prediction, correspondence, objectives, external baselines, screening, retrieval, engineering, newer EPIC reports and AbCite.

## Layer 3: branch and source provenance

Thirty branch pages show role, HEAD, ahead/behind and exact differences from original main. The full explorer contains 4,913 path/blob versions with memberships; the evidence-location catalogue includes all files under its documented filter. Do not relocate frozen files for cosmetic tidiness. Preserve the old 17-snapshot archive.

## Plot designs for future evidence-bound figures

| Question | Display | Required guardrail |
|---|---|---|
| Representation/objective effect | Paired-difference intervals around zero | One cohort and declared uncertainty unit; pointwise versus simultaneous separated |
| Structural PLM selection | Every real layer versus its own random-width control | All 10 contrasts, tie-window selection and no-promotion verdict |
| Rescue | Corruption benefit and clean cost in separate panels | Equal-complex levels differ from equal-component deltas; repeated conditions are not samples |
| Contact usefulness | P@10/P@50, recall, precision-recall curves | Matching prediction grid; never derive P@k from AP |
| EPIC v2 | Single model→unchanged ensemble→component ensemble | Frozen per-task selection and failed contact-selection transfer |
| RePaRank | Sequence, uncentered mismatch, corrected-centered | Separate macro/pooled metrics and input-access caveats |
| AbCite | Separate figure/page/VQA/real-media panels | No fixture/held-out/synthetic/official-harness mixing |

These are presentation specifications, not claims that new plots have been computed from off-Git predictions. The current HTML provides source-linked cards and complete searchable tables.

## Adding results

Attach terminal artifacts before upgrading a report-only card. Register numeric JSON selectors and expected values. Keep this dated source snapshot immutable; create a new dated snapshot for newer HEADs. Rebuild/check the atlas and run the historical-preservation verifier. A newer date or stronger prose alone cannot upgrade evidence.
