# Previously exposed SAbDab2 benchmark

This directory preserves the compact evidence from the single authorized
historical SAbDab2 measurement. It is **previously exposed, single-opening, and
measurement-only**. It is not a fresh blind test and must not be used for model
selection, calibration, threshold choice, checkpoint choice, or protocol
promotion.

- `CONCLUSION.json` contains the compact metric and intervention summary.
- `FROZEN_ENSEMBLE_TEST_RECEIPT.json` binds the immutable result and records
  that selection was not performed on the exposed benchmark.
- `MANIFEST.json` preserves the source authority.

The full pair-level result is intentionally excluded from Git.
