# ElasticABF 4-to-2-to-4 recovery gate (v2)

This directory preserves the compact audit and state receipts for an earlier
real-OAS ABF-35M 4-to-2-to-4 DDP/DCP correctness gate. It is retained as
historical recovery evidence; the later v4 result is the recommended entry
point in the result index.

The gate authorizes no production pretraining, downstream evaluation, test
access, biological conclusion, model selection, or performance claim. Raw
cluster logs and GPU telemetry are intentionally excluded.
